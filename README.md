## 🎮 软件介绍

**SCFA 内容中心** 是一个面向《最高指挥官：钢铁联盟（Supreme Commander: Forged Alliance）》Steam 版玩家的 Windows 内容管理工具。

通过它可以直接浏览、安装和管理社区地图与 MOD，不需要再手动寻找压缩包、复制文件或反复检查版本。

---

## ✨ 主要功能

### ☁️ 云端地图 / MOD

- 🗺️ 浏览社区地图
- 🧩 浏览社区 MOD
- 🔎 搜索内容
- 🖼️ 查看地图预览
- ⬇️ 一键下载安装
- 🕒 查看历史版本

### 🔄 一键同步

自动检查本地地图和 MOD：

- 自动补齐缺失内容
- 自动更新旧版本
- 相同内容不会重复安装
- 不会自动降级较新的本地版本
- 发现冲突时停止自动覆盖

### 📂 本地内容管理

- 扫描本地地图和 MOD
- 显示真实地图名称和版本
- 查看地图预览图
- 删除不需要的内容
- 删除和覆盖前自动备份
- 支持历史恢复

### ❤️ 跳过不喜欢的内容

不想安装某个地图或 MOD？

可以标记为 **“不喜欢”**，以后执行一键同步时会自动跳过。

仍然可以随时手动安装。

### 👤 账号与管理

目前已经支持：

- 用户注册 / 登录
- 用户资料
- 登录状态保存
- 离线模式
- 管理员权限
- 用户管理
- 服务状态与诊断

---

## 👑 管理员发布

地图和 MOD 目前采用 **管理员发布模式**。

管理员可以在软件内：

- 选择本地地图 / MOD
- 检查内容结构
- 自动生成发布包
- 校验版本和文件
- 生成地图缩略图
- 准备云端发布内容

🚧 **软件内一键上传并发布到云端功能仍在开发和部署测试中。**
