# SCFA 内容中心 C# V4.0.0-dev33

这是从 `V3.0.0-dev51` Go/Win32 工程迁移出的第一版 C# / WPF 工程，目标不是套壳，而是逐步替代原客户端。

## 当前已经迁移

- .NET 8 + WPF，统一深色科幻设计系统、自绘窗口框架、Fluent 图标导航与明确选中态；支持完整/紧凑侧栏、980×680 到大屏自适应布局和 Per-Monitor V2 DPI。
- 登录 / 注册，对接原 `/v1/auth/*` API。
- Windows DPAPI 加密会话、Token 到期/API 身份校验、自动登录与退出登录。
- 原生产 HTTPS 地址与 SHA-256 证书固定逻辑。
- 读取原 COS：地图 `scfa/manifest/latest.json`、MOD `scfa/manifest/mods.json`。
- 本地地图扫描：`.scmap` + `*_scenario.lua` + `map_version` + map/save/script 引用校验；限制扫描深度/数量并拒绝重解析点。
- 本地 MOD 扫描：`mod_info.lua` + `uid/version`；使用同一套安全目录遍历。
- Go `scfacore` 的版本标准化、版本比较、内容身份匹配策略；扫描损坏项仍参与精确匹配并可自动修复。
- `scfa-content-sha256-v1` 目录内容指纹算法。
- 云端清单/ZIP 限流、磁盘空间预检、SHA-256 校验、重复路径/目录穿越/异常压缩比检查、安全解压、安装、旧目录备份与失败回滚；大文件传输不受清单短超时影响，网络中断时可基于 ETag/Range 自动续传并最多重试三次。
- 一键同步：补缺失、更新旧版本、修复同版本内容不一致；保护本地较新版本不自动降级；支持取消并阻止模糊匹配。
- 云端内容中心支持名称/ID/版本/目录/作者/说明/分类/标签/别名搜索，安装状态与分类筛选，名称/发布时间/大小/状态排序，收藏和最近安装筛选，以及只安装缺失、旧版或损坏项的可取消批量操作。
- 内容详情兼容作者、说明、分类和标签等未来清单字段；当前生产清单没有这些字段时会明确显示“未提供/未分类”，不生成演示数据。
- 本地内容即时搜索、详情和目录快捷打开；本地地图/MOD可在完整备份后安全卸载，之后可从历史备份恢复或从云端重新安装。
- 下载/安装任务真实进度、单任务取消/失败重试、已结束任务清理与本地日志。
- 内容管理 UI 第二阶段：云端与本地地图/MOD采用统一搜索工具栏、真实统计、状态徽标、数据表与详情操作区；同步中心改为安全策略控制台，下载任务增加队列指标、进度和失败/中断状态表达，并通过 980×680 紧凑布局验证。
- 投稿与维护 UI 第三阶段：投稿中心加入四步工作流、资料完成度、输入计数与记录详情；本地备份、云端历史、诊断中心和客户端更新统一为真实统计、状态徽标、表格/详情与安全操作区。
- 管理员工作区 UI 第四阶段：投稿审核改为真实队列与决策台，用户管理增加账号/状态/活动会话统计和受控操作台，服务器审计增加四项服务健康、全文搜索、异常统计与记录详情；写操作继续执行 RBAC 校验和二次确认。
- 设置工作区 UI 第五阶段：首次设置升级为三步安全引导，实时显示检测数量与配置完成度；软件设置改为五类标签页控制台，集中展示草稿状态、配置完整度、目录/API/COS/服务器健康和固定底部保存区，并完成 980×680 紧凑布局验证。
- 启动阶段诊断日志；调试时可用 `SCFA_CONTENT_HUB_DATA_DIR` 隔离日志、会话和其他应用数据。
- 首页真实扫描、全部同步与账号服务健康检查快捷操作。
- 登录页和首页完成产品级视觉重构：登录页展示安全能力并在无消息时隐藏提示区域；首页提供内容指挥台、真实地图/MOD/任务/问题指标、运行状态与安全工作流，不使用演示数据。
- 设置页使用独立编辑草稿，未保存输入不会污染运行配置；支持放弃修改、载入推荐默认值、目录预检、保存时按需创建玩家目录，以及账号 API、COS 清单和服务器功能的分项/全部只读检测。游戏目录、Maps/Mods、API/TLS、COS、更新、离线/自适应行为和服务器相对路径均在原子保存成功后才生效。
- 首次设置向导：Steam 注册表、多 Steam 库和 C-Z 常用位置检测；兼容根目录或 `bin` 下的标准主程序，以及带 `game.dat` 和多项 SCFA 特征文件的改名 PE 主程序；默认使用玩家文档目录，不会自动写入游戏安装目录的原生 Maps/Mods；内容目录必须为非嵌套的安全绝对路径。
- 诊断中心：版本、系统、配置、目录、DPAPI 会话、账号 API、投稿、Updater、COS 清单及报告导出。
- 历史备份：每次覆盖前写入元数据与内容 SHA-256；可浏览、筛选、删除和安全恢复，恢复前自动再做快照。
- 云端历史版本：当前版本来自 COS 正式清单；历史记录来自可配置真实 API，安装历史版本前二次确认并自动备份。
- 客户端更新：Stable/Beta/Developer 通道、大小/PE/SHA-256 校验、任务取消，以及独立进程原子替换、失败恢复和旧文件清理。
- 投稿中心：支持选择或拖入玩家内容目录、名称/作者/说明/分类/标签元数据、可选预览图校验与本机草稿恢复；只接受本地校验通过且版本一致的内容，安全生成单顶层 ZIP、计算内容/包双 SHA-256，显示真实上传进度并支持取消后重试。
- 投稿审核、用户角色/状态、会话撤销、服务器健康和平台审计页面；全部按服务器 Token/RBAC 权限显示与执行。
- 任务记录持久化；异常退出后的运行中任务会在下次启动标记为“已中断”。
- GitHub Actions Windows 自动编译。
- 稳定性加固：自动同步不再仅凭显示名称覆盖本地内容，带标签版本不再因数字相同而误判；投稿上传脱离 12 秒普通 API 超时；下载严格执行清单包大小。
- 登录成功后通过 `/v1/auth/me` 复核身份；损坏配置会保留备份并提示用户；自更新执行前会重新校验 SHA-256，启动更新器失败时恢复旧客户端。
- 普通客户设置页默认只显示游戏目录、客户端行为和本机数据；账号连接、云端存储和服务器路径归入管理员可见的高级设置。诊断页改用客户语言，主界面战略网格、轨道线和等高线背景增强可见度。
- 同步历史持久化：完成、取消和失败记录写入本地安全数据目录，重新打开同步中心或软件后可恢复最近记录；同步历史最多保留 30 次。
- 背景视觉第二轮：增加低对比度斜向光带、连续等高线、分段航迹和多层环形结构，提升战略空间层次，同时保持内容区域清晰。
- 背景图片接入：使用已确认的 2048×1152 指挥舰桥图片作为主内容区底图，采用自适应铺满、深色遮罩和低透明度战术纹理，确保文字可读。
- 背景图片更新：替换为用户确认的蓝色行星与机甲场景，按默认窗口比例自适应铺满并降低遮罩强度，保留右下角主体和上方行星光弧。
- 云端历史绑定修复：只读统计属性明确使用单向绑定，避免进入云端历史页面时弹出 TwoWay/OneWayToSource 绑定错误。
- 总览页面第二轮：增加真实最近活动和系统健康摘要，补齐任务、目录、存储、网络与客户端状态，保持与确认的战略背景和半透明卡片风格一致。
- 背景网格移除：移除主内容区额外的 64px 战术网格叠加，只保留用户确认的背景图片、暗色可读性遮罩和低对比度空间结构。
- 背景可见度优化：提高背景图片可见度并降低全屏遮罩；普通卡片、重点卡片、工具栏和内嵌区采用分层半透明深色底，表格仍保留较高文字对比度。
- 不依赖第三方测试包的核心回归测试，覆盖内容身份、版本、安全 ZIP 路径、配置恢复/并发保存，以及投稿校验、预览图、草稿与上传进度流。

## 服务端契约与外部条件

- 已公开并实际验证：`/healthz`、`/v1/auth/*`、COS 当前地图/MOD清单；投稿健康状态为就绪，普通用户投稿记录只读路由为 `/v1/submissions/mine`；参考文档确认 `/v1/admin/users`。
- 生产服务没有公开 OpenAPI。投稿、审核、用户变更、会话撤销、审计和内容历史使用安全的相对路径配置，默认分别为 `/v1/submissions`、`/v1/admin/submissions`、`/v1/admin/users`、`/v1/admin/audit`、`/v1/content/history`。
- 设置页可修正这些相对路径，但不能把管理请求改到其他主机；所有响应限制为 4MB，权限和服务器错误会原样显示，不生成演示数据。
- 发布采用“投稿 → 服务器审核通过 → 服务端发布”的安全链路；客户端不直接保存或使用长期 COS SecretKey 执行发布。
- 当前生产 Updater 报告“已就绪但尚无发布版本”，因此自更新替换器已通过临时端到端测试，但暂无生产更新包可下载。
- 当前电脑已验证可将 `E:\SCFA` 识别为游戏根目录并准确定位 `bin\game.exe`；仍需由用户确认玩家 Maps/Mods 目标后再执行真实内容安装验收。

客户端功能已实现；会改变生产用户、投稿或审计数据的管理操作仍需使用有权限的真实账号做授权验收。

## 编译

Visual Studio 2022：安装 **.NET 桌面开发** 和 **.NET 8 SDK**，打开 `SCFA.ContentCenter.sln`，选择 Release / Any CPU 或直接运行项目。

PowerShell：

```powershell
.\build.ps1
```

输出：`artifacts\win-x64\SCFA内容中心.exe`

核心回归测试：

```powershell
.\run-regression-tests.ps1
```

## 配置兼容

C# 版继续读取 `%LOCALAPPDATA%\SCFAContentHub\config.json`。序列化时使用 `JsonExtensionData` 保留未知字段，降低覆盖旧 Go 配置时丢字段的风险。

自动化调试可设置 `SCFA_CONTENT_HUB_CONFIG_DIR` 和 `SCFA_CONTENT_HUB_DATA_DIR`，使测试配置、日志及登录会话完全写入临时目录，不接触真实用户数据。
