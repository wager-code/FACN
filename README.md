## 🎮 软件介绍

**SCFA 内容中心** 是一个面向《最高指挥官：钢铁联盟（Supreme Commander: Forged Alliance）》Steam 版玩家的 Windows 内容管理工具。

通过它可以直接浏览、安装和管理社区地图与 MOD，不需要再手动寻找压缩包、复制文件或反复检查版本。

---

## ✨ 主要功能

### ☁️ 云端地图 / MOD

- 🗺️ 浏览社区地图
- 🧩 浏览社区 MOD
- 🔎 搜索内容
- 🖼️ 查看地图预览
- ⬇️ 一键下载安装
- 🕒 查看历史版本

### 🔄 一键同步

自动检查本地地图和 MOD：

- 自动补齐缺失内容
- 自动更新旧版本
- 相同内容不会重复安装
- 不会自动降级较新的本地版本
- 发现冲突时停止自动覆盖

### 📂 本地内容管理

- 扫描本地地图和 MOD
- 显示真实地图名称和版本
- 查看地图预览图
- 删除不需要的内容
- 删除和覆盖前自动备份
- 支持历史恢复

### ❤️ 跳过不喜欢的内容

不想安装某个地图或 MOD？

可以标记为 **“不喜欢”**，以后执行一键同步时会自动跳过。

仍然可以随时手动安装。

### 👤 账号与管理

目前已经支持：

- 用户注册 / 登录
- 用户资料
- 登录状态保存
- 离线模式
- 管理员权限
- 用户管理
- 服务状态与诊断

## 👑 管理员发布

地图和 MOD 目前采用 **管理员发布模式**。

管理员可以在软件内：

- 选择本地地图 / MOD
- 检查内容结构
- 自动生成发布包
- 校验版本和文件
- 生成地图缩略图
- 准备云端发布内容

当前源码已具备地图/MOD 的打包、上传、发布、下架、版本档案与恢复链路。正式发行前还需核对实际客户端更新通道和部署构建。

## 🚧 项目状态

项目目前仍在持续开发中。

当前源码候选版本：**V4.0.0-dev62**（PR #5 已合并，待发行）。

现有发行基线：**V4.0.0-dev61**。当前仍是开发版，去掉 `dev` 前需要完成实际更新通道与发布验收。

### dev62 修复（2026-10-02，已合并，待发行）

客户端和网关发行由 GitHub Actions 构建，附带 SHA-256/来源记录，开发版保留 dev 标记。修改 .github/releases/release.json 的发行请求触发完整验证，成功后发布资产。

本轮修复汇总在 [PR #5](https://github.com/wager-code/FACN/pull/5)：

- 客户端更新：下载文件关闭后再计算 SHA-256，修复 Windows 文件占用导致的更新失败。
- 客户端版本比较：支持 `dev61 → dev62` 等开发版序号、正式版和预发布版顺序；保留地图/MOD 原有版本保护规则。
- 更新缓存与并发：复用包时重新核对清单大小、哈希与 PE；同一更新服务的并发下载合并为一次传输。
- 更新页面：检查、下载与安装共用操作状态；通道或包信息变化后清除旧安装状态，相同包重复检查保留安装就绪状态，失败后可重试。
- 安装与冲突清理：替换后取消会恢复旧目录并保持取消状态；恢复失败保留旧副本并明确报告。
- 内容备份与恢复：复制前后核对完整指纹，旧格式备份也验证暂存与落盘；恢复、安装和卸载共用互斥门，失败回滚并保留恢复前备份，拒绝祖先目录连接和嵌套备份目录。
- 账号连接：服务器、API 路径或证书身份变化时清除旧令牌，保存会话严格绑定规范账号地址；拒绝含用户信息、查询参数、片段或非 HTTP(S) 协议的地址。
- 管理员鉴权：8 秒总期限覆盖响应头和正文，实际读取最多 64 KiB，超大或无效 JSON 不授予权限。
- COS 请求：分别限制元数据、小对象和大包操作时间，保留取消语义和安全错误输出。
- 并发发布：缩小清单锁范围，下载与包校验期间允许无关下架；提交前重新检查最新清单。
- 客户端启动与回滚：新客户端初始化并显示登录窗口后才确认更新；启动失败或超时恢复旧程序，清理前复核路径和哈希。
- 网关健康检查：公开安全的版本与 Git 提交号，便于识别实际运行的构建。
- updater v2：模块化下载、校验、缓存、安装、运行中二进制验证与失败回滚，并提供只读检查。

自动验证涵盖客户端核心回归、资料/档案页和更新页 WPF smoke、真实客户端更新启动/失败场景、网关回归以及 updater 的安装与回滚测试。Windows CI 还构建自包含单文件候选包，使用独立更新进程验证替换、初始化失败回滚及重试；CI 的旧版夹具来自同一源码的较低版本构建。隔离包测试使用模拟传输，实际线上更新通道需另行验收。进度以 [GitHub Actions](https://github.com/wager-code/FACN/actions) 和 PR 状态为准。

**dev61 首次迁移：** 旧客户端的版本判断无法识别 `dev61 → dev62`，因此首次需要关闭旧客户端、备份原程序并手动替换为新版。新版修复后可正确比较后续开发版更新。

## 🛠️ 开发者

本项目使用：

- C#
- .NET 8
- WPF

开发者可以使用 Visual Studio 2022 打开：

```text
SCFA.ContentCenter.sln
```

`build.ps1` 默认构建 Windows x64 自包含单文件包到 `artifacts/win-x64`，无需目标电脑预装 .NET；可通过 `-OutputDirectory` 指定产物目录。

详细开发、测试和服务器相关资料统一放在 **[docs/ 项目手册](docs/README.md)** 中。

新电脑、新开发者或 Codex 新会话开始前，请先阅读 **[docs/00_START_HERE.md](docs/00_START_HERE.md)**。
