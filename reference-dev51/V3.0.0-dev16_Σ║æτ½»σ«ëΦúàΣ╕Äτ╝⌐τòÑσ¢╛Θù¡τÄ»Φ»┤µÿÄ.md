# SCFA 内容中心 V3.0.0-dev16

## 本轮目标

把云端地图 / 云端 MOD 从“可浏览、可下载”推进到真实安装闭环，同时补上管理员独立缩略图管理，所有状态只来自真实本地扫描和云端清单。

## 已完成

- 云端当前地图 / MOD 支持“安装到游戏”。
- 已安装资源支持真实更新 / 修复安装；更新走现有安全替换与历史备份流程。
- 新安装流程：下载正式包 → ZIP SHA-256 → ZIP 结构与安全检查 → 安全解压 → content_sha256 → 写入游戏 Maps / Mods → 重新扫描。
- 目标目录已存在但未确认属于同一资源时拒绝覆盖，避免误删玩家文件。
- 本地扫描未完成时不伪造“未安装”；按钮与卡片显示“待检测 / 本地扫描中”。
- 本地与云端真实一致时显示“已安装”；远端更新时显示“有更新”；同版本内容冲突时显示“需修复”；本地版本更高时显示“本地较新”。
- “查看详情”显示真实内容 ID、版本、状态、大小、时间、SHA-256、云端文件、缩略图来源与当前本地状态。
- 管理员可为当前正式地图 / MOD 手动选择 PNG/JPG/JPEG 作为独立云端缩略图。
- 独立缩略图上传到版本化 thumbnails 路径并写回 manifest.thumbnail，不修改地图 / MOD ZIP，不改变 content_sha256。
- 缩略图上传前做格式、文件大小、像素尺寸和总像素安全检查；大图自动缩到最大边 1024。
- 历史地图不允许用当前版本缩略图覆盖；历史卡片继续从自身版本资源中取图。
- 正式 EXE 的 PE FileVersion / ProductVersion / embedded manifest 统一为 3.0.0.16，且仍为 Windows GUI 子系统。

## 明确未完成 / 不伪装完成

- 腾讯云账号 API、Token、正式 RBAC 尚未接入；当前仍为开发登录验证。
- 普通用户投稿上传、我的投稿服务器状态尚未接入。
- 服务器不可篡改平台审计日志尚未接入。
- Developer / Beta / Stable 客户端自动更新通道尚未接入。
- MOD 历史版本目前没有像地图历史版本一样完整索引展示；本轮只安装 MOD 正式当前版本。

## 实机重点回归

1. 设置真实 SCFA 游戏根目录，打开云端地图 / MOD。
2. 选一个未安装的当前资源，点击“安装到游戏”，确认安装后本地重新扫描。
3. 对已有旧版本资源执行“更新到最新版”，确认历史备份产生且状态刷新。
4. 管理员对当前云端资源执行“更换缩略图”，确认卡片刷新，且 ZIP / content_sha256 未变化。
5. 最大化 → 还原 → 拖大 / 拖小窗口，确认 dev15 的缩放稳定性没有回归。
