# SCFA 发布中心 V2.2 UI Design System

## 基准
- 参考画布：1586 × 992
- 宽侧栏：256 DIP
- 紧凑侧栏：80 DIP
- 主内容左边界：约 288 DIP
- 主内容有效宽度：约 1218 DIP
- 页面画布高度：940 DIP
- 小窗口阈值：1120 × 760 DIP

## 色彩
- Background `#020F24`
- Sidebar `#021026`
- Surface `#07172E`
- Surface Raised `#0C1E3A`
- Border `#233A5B`

- Text Muted `#6A7F9F`

## 组件规则
- 卡片：11–12 DIP 圆角、1 DIP 低对比描边。
- 主按钮：蓝/分类色渐变；次按钮使用深色 Surface；危险按钮只用于删除/下架。
- 导航：当前项蓝色渐变/描边；未选中图标按业务类别保留颜色。
- 大型入口：图标 + 标题 + 次级说明，不使用单行大按钮代替卡片。
- 列表：深色表头、交替行、选中行蓝色、状态列语义色。
- 云端连接卡：右上固定 330×88，状态点 + 标题 + Region + 云图标。
- DPI：所有坐标使用 DIP；禁止按窗口宽度成比例拉伸单个控件。
