# SCFA 内容中心：产品要求与完成状态

本文件记录项目负责人在开发过程中明确提出的长期要求，供换电脑或换开发者后继续使用。状态以 `V4.0.0-dev61` 客户端及已验证服务为准；历史设想不等于已上线功能。

状态含义：**已实现**＝客户端已有并通过相关检查；**部分完成**＝还有服务端或跨设备工作；**待实现**＝尚无可用实现；**已取消**＝不再列入产品范围。

## 账号和权限

| 要求 | 状态 | 验收边界 |
| --- | --- | --- |
| 用户注册、登录和会话管理 | 已实现 | 连接独立账号服务；登录身份由服务端复核，会话本机加密保存。 |
| 管理员管理用户、查看服务审计 | 已实现 | 按服务端身份与权限显示入口；实际写操作仍受服务端权限控制。 |
| 只有管理员发布地图和 MOD | 部分完成 | 普通用户无客户端发布入口；管理员可准备材料。真正阻止旧服务端投稿路由、授权云端发布，还需服务端实施。 |
| 玩家上传投稿和管理员投稿审核 | 已取消 | 不再恢复玩家投稿、第三方审核渠道或旧审核页面。 |

## 地图、MOD 与本地管理

| 要求 | 状态 | 验收边界 |
| --- | --- | --- |
| 地图和 MOD 存在 COS，账号服务只处理身份和管理能力 | 已实现 | 客户端从正式清单读取内容；不把长期 COS 密钥放入客户端。 |
| 管理员可在软件后台轮换 COS 写入凭据，玩家无需更新客户端 | 部分完成 | dev56 有独立的“管理员设置”入口，仅超级管理员可见。发布网关已部署，提交时先验证 COS 访问再加密保存；管理员报告更正密钥后已配置成功，尚待首次发布验收。玩家下载当前公开对象仍无需密钥。 |
| 地图/MOD 目录可由用户设置 | 已实现 | 扫描用户选定的真实目录；不擅自创建或移动游戏目录。 |
| 显示游戏真正识别的地图名和地图预览图 | 已实现 | 优先读取地图文件；同时保留文件夹和内容 ID 供辨认。发布列表可按游戏名或文件夹名搜索。 |
| 云端 MOD 列表显示可用缩略图，云端地图和 MOD 的详情预览可点击放大 | 已实现 | 复用已有本地预览或清单缩略图；没有预览时保持文字显示。点击详情图打开大图窗口，不修改游戏文件。 |
| 在软件内快捷删除自己的本地地图或 MOD | 已实现 | 删除前备份并核对内容；支持从备份恢复。云端清单仍有的内容可能在以后同步时重新安装。 |
| 共用地形的官方战役地图可识别，但不当成独立发布包 | 已实现 | 显示名称、版本和预览；发布或独立安装需要完整地图结构。 |

## 同步安全

| 要求 | 状态 | 验收边界 |
| --- | --- | --- |
| 一键同步云端地图与 MOD | 已实现 | 补齐缺失、更新旧版本，必要时修复同版本内容差异；支持取消和任务状态。 |
| 不重复下载或覆盖完全一致的文件 | 已实现 | 使用版本、SHA-256 和整目录内容指纹判断；再次同步一致内容时跳过。 |
| 不装错版本、不自动降级 | 已实现 | 发布标签和游戏内部版本分别核对；保留玩家本地较新版本。 |
| 重复目录与冲突地图安全处理 | 已实现 | 自动同步不猜测要覆盖哪个目录。单项人工确认后才会下载、校验、备份并清理冲突。 |
| 失败时可恢复原文件 | 已实现 | 覆盖前备份；安装失败尝试回滚，历史备份可恢复。 |
| 按账号标记“不喜欢”，一键同步自动跳过 | 部分完成 | 本机按账号隔离且可取消标记；手动安装仍允许。偏好尚未通过账号服务跨电脑同步。 |

| 要求 | 状态 | 验收边界 |

| 只有通过 Steam 版兼容检查的地图/MOD 才上架 | 部分完成 | 当前自动检查文件结构、路径、版本和哈希；Steam 与 FAF 脚本语义差异仍须管理员人工检查。 |
| 管理员在软件内一键打包、上传并上架地图/MOD，无需另开 COS 网页 | 部分完成 | 客户端与独立发布网关已实现短期授权、暂存上传、独立包校验、清单备份、串行提交和结果复核；负责人报告地图发布成功，MOD 发布与玩家端安装、重复同步仍待验收。 |
| 云端重复 ID、目录或同版本不同内容不得无声覆盖 | 部分完成 | 本地与独立发布网关均检查冲突、版本、正式对象和线上清单哈希；未验证跨外部写入者的 COS 原子条件提交，生产需保持单实例并限制旁路写入。 |
| 管理员可查看版本档案并恢复已下架/历史版本 | 部分完成 | dev61 客户端与发布网关已有档案查询和恢复接口；代码与回归覆盖已加入，仍需部署当前网关并用真实管理员账号完成生产验收。 |
| 管理员可在云端地图/MOD 页面下架指定内容 | 部分完成 | dev60 客户端改为调用独立发布网关；服务端只从对应公开清单移除指定 ID，写前备份并写后核验，不删除云端包、缩略图或玩家本地文件。服务端升级和真实账号验收尚未完成。 |

## 当前最重要的未完成项

1. 完成独立发布网关的真实 COS 验收：部署、备份、HTTPS 路由和未登录拦截已完成；先核实服务器上的凭据状态，再测试地图/MOD 上传、权限、重试、同步与回滚。长期密钥不得下发玩家。
2. 把“不喜欢”偏好与账号服务同步，允许用户换电脑后保留选择。
3. 对 Steam 版与 FAF 专属地图/MOD 的兼容性建立可核对的规则，并在正式上架前由管理员确认。
4. 正式对外发布前，用真实账号、隔离的游戏内容目录与生产清单完成安装、再次同步、冲突恢复和回滚验收；客户端更新通道也要有实际发布包才能完成生产验收。
